# addons/alexander

Módulos **específicos** para las empresas de Alexander Piña (Alexander Group).

## Convención de nombres

```text
justech_alexander_<nombre_funcional>
```

Ejemplos **futuros** (aún no se deben crear):

- `justech_alexander_base` — datos y configuración base del grupo.
- `justech_alexander_reports` — reportes específicos del grupo.
- `justech_alexander_security` — grupos, reglas y permisos multiempresa.
- `justech_alexander_intercompany` — automatizaciones intercompañía.

## Reglas

- **No se deben crear módulos Odoo funcionales todavía.** Solo se permite crear un
  README describiendo su propósito futuro cuando sea estrictamente necesario.
- Todo desarrollo nuevo usa el prefijo `justech_` y, para este proyecto,
  preferiblemente `justech_alexander_`.
- No incluir información fiscal inventada ni datos productivos.
- No incluir credenciales, tokens ni certificados.
- Compatible con **Odoo 19** (`version: 19.0.x.y.z`).
